All gates below ran serially on the integrated Linux x86-64 source with the
existing pinned compiler overlay and native toolchain; no dependencies were
installed or updated. Every reference archive and qualification is fresh.

- Python suite: **585 tests**, comprising 535 published-main tests, 49 TGA tests
  and one additional CI preservation method
- Complete proof: **149 laws**, with the exact verdict `All terms check.`;
  these are structural facts, not a universal codec/IO theorem
- Syntax, project, API drift and Git whitespace checks pass
- TGA memory: **169 native images, 155 checked-only controls, 1,311 complete
  observations and 1,024,632 bytes per CPU-1/CPU-2/JavaScript lane**; independent
  replay validates all 1,224 seals and 181 owned-command receipts
- TGA partitioning: **43 partitions**, maximum **185,890 generated bytes** under
  the unchanged 196,608-byte/32-action limits; all action/input/native-capture
  identities match the approved isolated workload. The four-byte difference
  from its 185,894-byte maximum is the shorter absolute import path
- PNM files: **156 native files, 74 checked-only controls, 626 primary records
  and 129,072 bytes per lane**, plus **1,009 closure, four sparse and one
  exact-cap record per lane**; independent replay validates all 1,179 seals and
  103 owned-command receipts, including measured resource ceilings
- Canonical clean-loader conformance and strict full-record replay: **261
  scenarios / 40,101 words / 333 QOI bytes / 23 palette words per lane** on
  CPU-1/CPU-2/JavaScript. Both replay implementations check nine negative
  mutations, including otherwise-valid altered QOI, palette and alpha-border

  also pass

The focused TGA run took 1,013.848 seconds and PNM-file run 674.053 seconds on
this local host. These are correctness-run observations, not hosted runtime or
representative performance qualification.
